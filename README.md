## 比价最容易算错的三件事

**第一件：流量跑完之后会发生什么。**

市面上两种组合模式。一种是“大带宽 + 月流量”，比如 500Mbps 端口配 1TB/月，峰值快，跑完通常限速到 1Mbps，次月 1 号重置。另一种是“小带宽 + 不限流量”，比如 5Mbps，天花板低但不会突然断。新手最常犯的错是看到“1Gbps”就下单，忽略流量跑完那半个月只能用 1Mbps 撑着的体验。

LightLayer 台湾节点的下单页正好把这两种模式摆在一起：TW-VP02 是 10Mbps 配不限流量，TW-VP04 是 20Mbps 配 1TB 流量。两档都是 1 核 1GB / 50GB SSD，价格差在带宽和计费方式上。买之前先想清楚你的业务是“持续小流量”还是“偶尔突发大流量”，答案不同，选的就不同。

顺带说一个细节：这两档的 IPv4 标注都是 Non-Native。需要原生 IP 跑特定业务的人，这一档不适合，得往别的产品线找。

**第二件：年付特价和优惠码经常不能叠加。**

年付特价方案通常是单独配置的，价格已经压过一轮，商家不会再让你叠优惠码；能叠码的往往是常规月付方案。所以看到“年付 6 折”这类宣传，先确认它指的是“年付价本身”还是“年付价再打折”。这两种说法的实际差额可能到 30% 以上，而且只在结算页最后一步才显示出来。

**第三件：续费价和首期价是两个数字。**

国内有商家会把“续费同价、不涨价”当成卖点写进宣传页，这件事本身就说明涨价在这个市场是常态。比价时把首期价和续费价分开记，第二年续费时才发现翻倍的例子不少。

## 便宜 VPS 的成本从哪里省出来

入门配置的行业常见值大概是这样：1 vCPU、512MB–2GB 内存、10–40GB SSD（NVMe 和 SATA 混着用）、1–3TB 月流量、100–1000Mbps 共享端口。低于这个配置还能更便宜的，基本都在别处做了取舍。

- **虚拟化方式**：主流是 KVM，能自选内核；极端低价还可能见到 OpenVZ，容器虚拟化，内核跟着宿主机走。
- **超售**：vCPU、内存、磁盘 IO 都可能超售。高密度节点加上超售算法，资源利用率上去了，你的实际性能下来了。
- **网络政策**：大带宽短时间能跑满，持续高吞吐或高并发会按公平使用政策限速或处置。
- **服务等级**：SLA 承诺偏松，宕机补偿低，工单响应慢，客服人手少。
- **功能裁剪**：快照、自动备份、DDoS 高防、额外 IPv4 都是付费附加；rDNS 有时候要开工单手动设置。
- **现金流**：年付一次性回款，省掉逐月催续费的运营成本，所以年付折扣能给得比月付狠。
- **硬件折旧**：上一代 CPU 和 SSD，加上大批量采购，单台成本能摊得很薄。

这些不等于骗。年付提前回款、租用合作机房机柜、用上一代至强配 RAID-10 SSD，都是真实存在的成本结构，能把年付价压到十几美元。真正要警惕的是价格低得没有解释：明显低于同配置市场均值一半，又没有说明省在哪里，大概率是超售严重、线路拥堵或者 NAT 共享。这是一条经验判断，不是统计数据。

## 哪些场景不该碰便宜 VPS

- 要求 SLA ≥ 99.99% 的金融、支付、核心业务
- 重 I/O 的数据库、实时语音视频、交易撮合
- 需要 ISO 27001 / SOC 2 审计日志、有数据主权要求的合规业务
- 长时间满核计算、CDN 回源洪峰、DDoS 频发的业务

## 拿到机器后的验货清单

1. **连通性**：从目标用户所在的网络做 `ping`、`mtr`、`traceroute`，重点记录晚高峰（20:00–23:00）的抖动和丢包，不要只看白天的数字。
2. **磁盘 IO**：用 `fio`、`dd`、`ioping` 快测，看的是稳定性不是峰值。邻居在跑大 IO 的时候你的数字会掉，多测几轮。
3. **CPU 稳定度**：`stress-ng` 连续跑 10–30 分钟，观察有没有掉频、温度节流的迹象。超售严重的机器在这个测试里会原形毕露。
4. **网络与端口**：`iperf3` 加实际文件上传下载，对比宣称带宽；顺便检测常用端口有没有被封。
5. **可靠性最小集**：立刻配好自动备份、跨商家异地冷备，启用防火墙和 Fail2ban，改掉默认 SSH 端口、禁用密码登录只用密钥。
6. **IP 信誉**：查这个 IP 在邮件黑名单、搜索引擎、反垃圾数据库里的记录，有问题马上开工单换。

在大厂实例上还可以顺手做几件事：Ubuntu 24.04 配 SSH Key 登录；`ufw` 只放行 22/80/443；1GB 内存的机器配 512MB–1GB swap，`vm.swappiness=10`；静态文件和大文件放对象存储，别占实例的 IO 和带宽；打开账单和流量告警。
